# Task Board

A full-stack task management application built with React, TypeScript, Node.js, Express, and Socket.IO.

## Features

### User Story 1 - Create Card
- Create new task cards
- Position validation
- Contract and integration tests

### User Story 2 - Edit Card
- Edit card details
- Real-time updates
- Card detail view
- Validation support

### User Story 3 - Delete Card
- Delete cards with confirmation
- Real-time synchronization
- Frontend and backend test coverage

### User Story 4 - Validation
- UUID parameter validation
- Backend validation middleware
- Frontend validation error handling
- Contract tests for validation scenarios

## Tech Stack

### Frontend
- React
- TypeScript
- Vite
- Socket.IO Client

### Backend
- Node.js
- Express
- TypeScript
- Socket.IO

### Testing
- Vitest
- Contract Tests
- Integration Tests

## Run Locally

### Install dependencies

```bash
npm install
```

### Start frontend

```bash
cd frontend
npm run dev
```

### Start backend

```bash
cd backend
npm run dev
```

### Run tests

```bash
npm test
```
